# Review readiness

Copy this file to `docs/store/review-readiness.md` in your app's repo.

The rule: every line is a clear yes with evidence before anything is submitted. Anything that is
not a clear yes blocks the submission. The date moves, never the gate.

Evidence is something another person can check again: a file and line, a command and what it
returned, a dated read of the console, a test on a real device with the build number.

Add a new set of sections for every version. Do not edit the old answers; they are the record of
what was true then.
